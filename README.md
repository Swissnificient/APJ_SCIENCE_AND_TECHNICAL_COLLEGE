# Brightwood Academy template

This is a simple static website: no framework or installation is required.

## Open it

Double-click `index.html`, or right-click it and select **Open With** your browser.

## Your first edits

1. In `index.html`, replace every mention of **Brightwood Academy** with your school name.
2. Replace the address, phone number, and email near the bottom of `index.html`.
3. Edit the headings and paragraphs directly in `index.html`.
4. In `styles.css`, change the colour values on the first line. For example, `--green` controls the main green used throughout the site.
5. Replace image URLs in `styles.css` later with your own photos. Search for `images.unsplash.com` to find them all.

Refresh the browser after saving a file to view your change.

## Files

- `index.html` — page content and sections
- `styles.css` — layout, colours, and responsive design
- `script.js` — the mobile menu interaction
